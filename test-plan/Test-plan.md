Test Plan

    1. Project Overview("What is about this project and what we are testing here?")
        This project focuses on manual testing of the Practice Software Testing (Toolshop) e-commerce web application.

        The main purpose is to evaluate core user flows such as login, registration, product search, and shopping cart functionality while practicing fundamental software testing techniques.

    2. Test Objectives("What is the goal of this test?")

        -Verify that core e-commerce functionalities work as expected.
        -Identify functional and usability defects.
        -Practice writing test scenarios, test cases, and bug reports.
        -Apply basic test design techniques where appropriate.
        

    3. Scope

        In Scope

            -Login
            -User Registration
            -Product Search
            -Shopping Cart

        Out of Scope

            -Payment Processing
            -Performance Testing
            -Security Testing
            -API Testing
            -Database Testing

    4. Test Types

        Functional Testing
        Positive Testing
        Negative Testing
        Exploratory Testing
        Regression Testing

    5. Test Environment

        -Operating System: Windows 11
        -Browser: Google Chrome
        -Testing Type: Manual Testing

    6. Entry Criteria

        -The application should be accessible
        -Core features should be available for testing
        -The test environment should be ready

    7. Exit Criteria

        -All planned test cases have been executed
        -Critical and high-priority defect have been documented
        -Test results have been reviewed

    8. Deliverables

        -Test Plan
        -Test Scenarios
        -Test Cases
        -Bug Reports
        -Test Desing Technique Examples
        -Test Summary Report
