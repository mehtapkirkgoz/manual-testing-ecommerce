Test Scenarios

    This document contains high-level test scenarios for the core e-commerce functionalities included in the project scope.

    1. Login Scenarios4

        -Verify login with valid credentials.
        -Verify login with invalid password.
        -Verify login with invalid email/username.
        -Verify login with empty required fields.
        -Verify password visibility bahavior.
        -Verify user can log out successfully.

    2. Registration Scenarios

        -Verify registration with valid user information.
        -Verify registration with an already registered email address.
        -Verify registration with empty required fields.
        -Verify registration with invalid email format.
        -Verify password validation rules.
        -Verify password and confirm password mismatch behavior.

    3. Product Search Scenarios

        -Verify search with a valid product name.
        -Verify search with a partial product name.
        -Verify search with a non-existing product.
        -Verify search with an empty search field.
        -Verify search results are relevant to the entered keyword.
        -Verify search behavior with special characters.

    4. Shopping Cart Scenarios

        -Verify a product can be added to the shopping cart.
        -Verify multiple products can be added to the cart.
        -Verify product quantity can be increased.
        -Verify product quantity can be decreased.
        -Verify a product can be removed from the cart.
        -Verify the cart total is calculated correctly.
        -Verify cart contents are retained while navigating between pages.
